1. Project Purpose

Exam Seat Finder is an independently developed educational project created to learn and demonstrate Java, Spring Boot, database integration, REST APIs, frontend development, and web deployment.

5. Student Information

The search feature accepts an admission number and uses it to look up matching examination records. Depending on the available record, the result may display a student's name, admission number, room, seat, course code, examination date, shift, program, semester, and section.

The search feature is not an authentication system. An admission number alone does not prove that a person is authorized to access information. Users should not search for or misuse another person's information.
